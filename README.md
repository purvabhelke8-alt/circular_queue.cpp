# 🔄 Circular Queue Using Array in C++

A simple and efficient **C++ implementation of Circular Queue using an Array**.

This project demonstrates the basic operations of a Circular Queue using a **menu-driven program**. 🚀

---

## 📌 Problem Statement

Implement a **Circular Queue using Array** and perform the following operations:

- ➕ Enqueue (Insertion)
- ➖ Dequeue (Deletion)
- 👀 Display
- 🚪 Exit

The queue uses a fixed size of **5 elements**.

---

## ✨ Features

- 🔄 Circular Queue implementation
- 📦 Array-based data structure
- ➕ Enqueue operation
- ➖ Dequeue operation
- 👀 Display queue elements
- 🚫 Queue Full condition
- ⚠️ Queue Empty condition
- 🔀 Menu-driven program
- 💻 Easy to understand C++ code
